# Guess The Evil Number 👹🎯

A fun beginner Python game where players try to guess the hidden evil number between 1 and 10.

## Features
- Hint system
- Attempt counter
- Interactive gameplay
- Fun themed responses
- Beginner-friendly logic building

## Concepts Used
- Loops
- Conditional Statements
- User Input
- Variables

## Learning Outcome
This project helped me understand loop control, repeated execution, and interactive game logic in Python.
